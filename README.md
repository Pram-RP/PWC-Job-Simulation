# PwC Power BI Job Simulation

## Project Overview

This repository contains Power BI dashboard solutions completed as part of the PwC Job Simulation.

The project consists of four separate dashboard tasks, each based on a different business scenario and dataset. The dashboards demonstrate the application of Power BI for data analysis, KPI reporting, data visualization, and presentation of business insights.

## Tools Used

- Power BI
- Data Analysis
- KPI Reporting
- Data Visualization
